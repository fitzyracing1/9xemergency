What this is

Lean HTML is a small set of attributes and a processing layer that sits on top of ordinary HTML. Current browsers ignore the new attributes. When the Lean layer is present, documents can prefer local and content-addressed resources, verify integrity, and reduce unnecessary network cost.

It is the practical first step toward the internet principles we care about: user agency, verifiability, and cost as a first-class constraint.

How it reduces cost

Local-first

Try the local store before the network. Repeated visits and shared content stop costing bandwidth.

Content-addressed

Identify resources by hash. Identical bytes are the same resource no matter where they came from.

Integrity

Verify what you received. Reduces the need to trust a single origin or CDN.

Declarative

Keep more behavior in the document. Less JavaScript means less weight and fewer moving parts.

Minimal usage

<html lean>
<link rel="stylesheet"
      href="/app.css"
      content-address="sha256-…"
      integrity="sha256-…"
      local-first>

<article content-address="sha256-…"
         integrity="sha256-…"
         local-first
         provenance="did:key:…">
  …
</article>

Current capabilities

  • Attribute scanning and progressive enhancement
  • IndexedDB content-addressed store
  • Service Worker for basic local-first caching
  • Integrity and provenance markers
